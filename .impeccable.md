# Design Context — TimeLens

Collected from the owner's own words while building the extension (October 2026).

## Target audience
The owner: a student and developer on Windows Chrome who spends long days in the browser across
coursework, AI tools (claude.ai, muse.ai), GitHub, and YouTube music. Wants to see where the time
goes and catch the moment they "slide into" doomscrolling or "forget what I started with".

## Use cases
- Glance at today's total and what's being timed right now (popup, top of the side panel).
- See drifts: when they left Work/Learning for distraction, and whether they came back.
- Review history like a phone: "like a mobile phone dashboard of everyday", modeled on iPhone
  Screen Time and Android Digital Wellbeing (day/week, most used, more detailed info).
- Fix categories and limits directly in the dashboard ("I don't want to use the Chrome feature").

## Brand personality / tone
- "Keep it minimal." "Remove all the unnecessary stuff."
- "Plain black and white and little colors." Colour only for status: green = tracking,
  amber = distracting, red = delete.
- "A little more modern" than a default chart; iPhone-level detail without clutter.
- Fast — the owner noticed lag and wants it gone.
- Lens, the magnifying-glass mascot, is the one playful element.

## Constraints
- Chrome side panel (~360px) and a 340px popup; dark only.
- Local-only: no network requests, so no hosted web fonts; system font stack stays.
- Small: the owner asked for the code "small as possible" (minified build in `dist/`).
- Tokens only (`styles.css`), checked with `validate_tokens.py --strict` from `D:\dev\skills`.
- Charts must pass the dataviz skill's checks (validate_palette.js, mark specs, tooltips on
  hover and focus, numbers also available as text).
